前置：局域网共享 & 系统安全策略

在访问共享文件夹前，需要先调整本机组策略，允许不安全的来宾登录。

打开组策略编辑器
按 Win + R，输入 gpedit.msc
  1. 路径：计算机配置›Windows 设置›安全设置›本地策略›安全选项
    找到「Microsoft 网络客户端：对通信进行数字签名（始终）」，设置为 已禁用
  2. 路径：计算机配置›管理模板›网络›Lanman 工作站
    找到「启用不安全的来宾登录」，设置为 已启用

02

注册 API 中转

使用 GeekAI 中转站进行充值与令牌管理，用于后续的推理与出图调用。

api.geeknow.top/register
  1. 注册账号后进入「账户余额」页面，选择充值金额（公司报销，用于推理和出图）
  2. 进入「令牌管理」，点击「新建令牌」
  3. 先添加渠道，再勾选分组（需要连两个令牌）
03

配置字字动画

3.1 · 安装视频插件

共享文件夹「其他资源」目录下有 video_plugin_6666 文件夹。

复制路径 将共享里的 6666 文件夹复制到本机：
软件(D:) › 字字动画 › internal › plugins › video_plugins

3.2 · 大模型渠道配置

在字字动画「创作设置 › 大语言模型设置」中，配置自定义文本模型渠道：

自定义渠道 1
Base URL：https://api.geeknow.top/v1
模型名称：gemini-3.1-pro-preview
自定义渠道 2
Base URL：https://api.geeknow.top/v1
模型名称：gpt-5.5
注意 渠道令牌需分别对应正确的分组（GPT 通道与推理/出图通道令牌不通用），填错会导致调用失败。
既梦API修改第九版.txt5.33 KB

3.3 · 图片 / 视频模型接入

在「图片模型管理」「视频模型管理」中分别选择「自定义渠道 — GeekNow」，填入对应 API Key，图片模型选用 gpt-image-2，视频模型选用 Seedance 2.0。

批量操作提示 故事板中「鼠标左键合并，右键分行」，最后需点击执行重排。
生成前提 先设置推理模板，再选择推理范围，随后在「批量生成」中依次选择「批量补充画面提示词」「批量生成图片」「批量生成视频」。

3.4 · 出图风格提示词

在作品创建页填写正向提示词，控制画面风格与字幕/BGM 排除规则：

Prompt 写实拍摄，电影级质感，真人现代都市剧影视风格，真实质感，保留细节。不得出现字幕，字体不透明度为 0%，大小为 0，无 BGM，只添加合适的音效。
04

视频高清处理

全部视频生成后需要手动做超分辨率放大处理，使用仙宫云的 GPU 实例运行 VSR（Video Super Resolution）工具。

xiangongyun.com — 仙宫云算力平台
  1. 在镜像市场搜索 VSR，选择 FlashVSR_Ultra_Fast 图片视频超清放大镜像
  2. 选择 GPU 型号（示例：RTX 4090 D 48GB），确认后部署实例
  3. 实例运行后点击 WebUI 进入操作界面
重要 算力按小时计费，用完记得点「销毁」释放实例，避免持续扣费。
